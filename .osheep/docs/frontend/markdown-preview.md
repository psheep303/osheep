# Markdown 预览

## 目标

让用户在工作台内直接以渲染后的形式查看 Markdown 文档，仿照 VS Code 的"打开预览"。

---

## 触发

- 当编辑区当前激活的 Tab 是 `.md` / `.markdown` / `.mdx` 文件时
- **预览 / 源码切换按钮放在标签页栏的最右侧**，与标签页同高度（仿 VS Code），不再悬浮在编辑器上方
- 切换状态保存在 Tab 上，不同 Tab 互不影响

---

## 行为

- 默认打开为源码视图（Monaco 编辑器）
- 切换到预览：将 Monaco 替换为渲染后的 HTML
- 切换回源码：继续编辑，未保存内容保留
- 预览基于当前 Tab 的内存内容渲染——用户在源码中改动后切到预览即可看到最新结果，无需保存

---

## 排版

- **左对齐**：预览内容靠编辑区左侧，不水平居中
- 最大宽度 980 px（避免行过长影响阅读）
- 内边距 24 px 上下、32 px 左右

---

## 渲染范围

- 标题、段落、强调、删除线
- 列表（有序 / 无序 / 任务列表）
- 行内代码 / 代码块（按语言着色将在后续接入）
- 表格
- 引用
- 链接、图片
- 水平分割线

---

## 安全

- 预览输出经过统一的 HTML 净化，移除脚本、危险属性
- 用户文件中的相对链接不解析为真实导航，避免误触

---

## 与编辑器联动

- 在预览模式下保存（Ctrl+S）仍生效：保存当前内存内容
- 重命名 / 删除联动规则与普通文件 Tab 一致：标题同步、删除态加删除线
