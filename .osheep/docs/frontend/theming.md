# 主题与配色

## 目标

让前端工作台的视觉风格与主流编辑器一致，降低用户上手成本，同时保证代码区始终是视觉重心。

---

## 当前默认主题

对齐 **VS Code Default Dark Modern**。

### 关键色板

| 用途 | 颜色 |
|------|------|
| 编辑器背景 | `#1f1f1f` |
| 外壳背景（活动栏 / 侧栏 / 标题栏 / 底部面板） | `#181818` |
| 主前景 | `#cccccc` |
| 次级前景 | `#9d9d9d` |
| 弱前景 / 占位 | `#6e6e6e` |
| Hover 背景 | `#2a2d2e` |
| 选中高亮 | `#04395e` |
| 焦点 / 强调色 | `#0078d4` |
| 区域分隔线 | `#2b2b2b`（务必保持极淡） |
| 错误前景 | `#f48771` |

---

## 配色原则

1. 编辑区使用稍亮的 `#1f1f1f`，外壳区使用稍暗的 `#181818`，让视觉重心始终落在代码上
2. 分隔线只用于必要的功能边界，颜色尽量接近背景
3. 任意活动 / 焦点状态统一使用强调色 `#0078d4`
4. Hover 与选中区分明显但不刺眼
5. 所有颜色集中由 CSS 变量驱动，便于后续接入主题切换

## 文件图标

- 当前阶段在文件树中只为**文件**渲染 16×16 SVG 图标，文件夹不出图标（只保留可旋转的 chevron）
- 字符型图标使用 SVG `<text>` 直接渲染色彩，常见特殊符号（`{}`、`</>`、`#`、`$_`、`<>` 等）采用矢量路径
- 覆盖范围：主流编程语言、Web 框架文件、配置文件、构建工具、数据库、压缩包、图像、文档、特殊文件名等数十种
- 调色尽量参考 GitHub linguist 与 Seti 主题，常见示例：
  - 脚本 / 配置：`.json` `#cbcb41`、`.yaml` `#cb171e`、`.toml` `#9c4221`、`.xml` `#0060ac`
  - 前端：`.js` `#f1e05a`、`.ts` `#3178c6`、`.tsx/.jsx` `#519aba`、`.vue` `#41b883`、`.svelte` `#ff3e00`、`.html` `#e44d26`、`.css` `#42a5f5`、`.scss` `#c6538c`、`.md` `#519aba`
  - 后端 / 系统：`.py` `#3572a5`、`.go` `#00add8`、`.rs` `#dea584`、`.java` `#b07219`、`.kt` `#7f52ff`、`.swift` `#fa7343`、`.rb` `#cc342d`、`.php` `#777bb4`、`.c/.h` `#599eff`、`.cpp` `#f34b7d`、`.cs` `#178600`、`.dart` `#00d2b8`、`.lua` `#2c2d72`、`.r` `#276dc3`、`.jl` `#9558b2`、`.hs` `#5e5086`、`.ex` `#6e4a7e`、`.clj` `#5881d8`、`.scala` `#dc322f`、`.pl` `#39457e`、`.nim` `#ffc200`、`.zig` `#f7a41d`
  - Shell：`.sh/.bash/.zsh` `#89e051`、`.ps1` `#012456`、`.bat` `#c1f12e`
  - 数据 / 媒体：`.sql` `#e38c00`、图像 `#a074c4`、压缩 `#ddb84a`、`.pdf` `#db5860`、`.lock` `#ddb84a`、`.env` `#ecd53f`
  - 特殊文件名：`package.json` `#cb3837` (npm)、`Dockerfile` `#2496ed`、`.gitignore` `#f14e32`、`README` 蓝、`tsconfig.json` 蓝
- 未识别类型回退为通用纸张轮廓，颜色 `#9d9d9d`
- 新建文件输入框中的图标会随用户输入的扩展名实时切换
