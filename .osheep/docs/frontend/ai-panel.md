# AI 面板

## 目标

把工作台右侧栏改造为 AI 协作主入口，承载 osheep 后续的需求 → 文档 → Todo → 执行流程。当前阶段仅落地最基础的「编写」能力——管理对话与基本 LLM 聊天。

---

## 顶层布局

右侧栏顶部使用 segmented 控件切换两个栏：

- 编写
  - 当前阶段唯一可用的栏
  - 负责创建 / 切换 / 搜索 AI 对话
  - 真正的对话框出现在中央代码区域，作为一个独立 Tab
- 维护
  - 占位栏，预留后续 PR 审查 / Issue 审查 / 自动维护功能
  - 当前阶段仅显示「后续阶段接入」提示

---

## 「编写」栏

### 顶部工具栏
- 标题：`编写`
- 「新建」按钮：创建一个新会话并在中央打开
- 「搜索」按钮：切换搜索输入框；输入后客户端按 `title` 子串过滤已加载会话列表

### 会话列表
- 每条会话显示：标题 + 相对时间（如 `34m`、`5h`、`1d`）
- 顺序：按 `updatedAt` 倒序
- 点击一条会话时：
  - 在中央编辑区打开一个 Tab，path 为 `__chat__:<id>`
  - 若该 Tab 已存在则直接激活
- 选中态：当前在中央编辑区激活的对话会高亮其在列表中的条目
- 列表悬停时显示删除按钮，点击需二次确认

### 会话标题
- 新建时默认 `新对话`
- 用户第一条消息发送后，若标题仍为默认，自动取这条消息前 24 个字符作为标题

## 中央对话 Tab

每个会话 Tab 的内部布局：

```
┌──────────────────────────────────────────────┐
│ 消息流（用户 / 助手交替气泡）                │
│ ...                                          │
├──────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────┐ │
│ │ 输入框（多行 textarea）                  │ │
│ │                                          │ │
│ ├──────────────────────────────────────────┤ │
│ │ Agent ▾   [发送]                         │ │
│ └──────────────────────────────────────────┘ │
└──────────────────────────────────────────────┘
```

### 输入框
- 仿 Claude Code：多行 textarea
- `Enter` 发送，`Shift+Enter` 换行
- 发送中禁用输入与按钮

### Agent 选择器
- 位于输入框底部
- 数据源：当前项目 `.osheep/agent/*.json`
- **未选择 Agent 时禁止发送**，按钮提示「请先选择 Agent」
- 对话中途可以切换 Agent
  - 切换后再次发送时使用新 Agent 的 `providerId`、`model`、`prompt`
  - 切换不会重写历史消息

### 消息流
- 顺序展示用户 / 助手消息
- 不显示 `system` 提示词（仅用于发往模型）
- 助手消息使用等宽字体；用户消息使用普通字号
- 当前阶段不做 Markdown 渲染、思考折叠、工具调用展示——预留为后续阶段

## Agent 提示词与上下文记忆

发送一条用户消息时，前端组装出 `messages` 数组：

1. 取当前选中的 Agent 的 `prompt`（非空时）作为第一条 `system` 消息
2. 拼接当前会话保存的历史 `user` / `assistant` 消息
3. 追加本次输入的 `user` 消息
4. 提交给后端 `/api/workspaces/:id/ai/chat`，后端调用 `${baseUrl}/chat/completions`

返回后：
- 把返回的 `assistant` 消息追加到会话
- 更新 `agentName` 字段为最近一次发送时使用的 Agent
- 保存到 `.osheep/session/<id>.json`

上下文记忆即「整条历史每次都重发」，当前阶段不做截断或摘要。会话过长后由用户自行新建会话。

## 会话文件结构

```json
{
  "id": "ses_abc123",
  "title": "新对话",
  "agentName": "需求拆解员",
  "createdAt": 1715000000000,
  "updatedAt": 1715000123456,
  "messages": [
    { "role": "user",      "content": "...", "timestamp": 1715000010000 },
    { "role": "assistant", "content": "...", "timestamp": 1715000012000 }
  ]
}
```

- `agentName` 仅作展示与默认选择，发送时仍以前端当前选中的 Agent 为准
- `messages` 不包含 `system`；`system` 由 Agent 的 `prompt` 实时注入

## 当前阶段不做

- 流式输出（实现完成后 UI 直接渲染完整回复）
- 多 Agent 并行 / 子 Agent
- 工具调用、文件附件
- 服务端摘要 / 长上下文压缩
- 删除会话后的「最近删除」回收站
