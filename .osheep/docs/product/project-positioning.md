# 项目定位

## 项目目标

osheep 的目标不是重新实现一个完整的 VS Code，而是提供一个以 AI 工作流为中心的 Web 开发工作台。

编辑器能力是基础设施，AI 协作流程是核心产品。

---

## 核心价值

1. 让需求先文档化，再进入开发
2. 降低 AI 与用户理解偏差
3. 将“生成”流程标准化、结构化
4. 让 AI 的执行过程可见、可控、可中断
5. 支持自托管与自定义模型接入

---

## 当前阶段定位

当前阶段聚焦以下方向：

- 单项目
- 单用户优先
- 需求到执行的闭环
- 轻量部署
- 前端体验接近 IDE，但不追求完整复刻 VS Code

---

## 非目标

当前阶段不追求：

- 完整 VS Code 插件生态兼容
- 多人协同办公
- 云原生大规模调度
- 全自动无人审批执行
- 完整维护模式闭环
