# 任务编排

## 目标

将文档生成、Todo 生成和执行开发统一为可排队、可追踪、可中断的异步任务。

---

## 任务类型

### document_generation
根据用户需求生成或更新 `.osheep` 文档

### todo_generation
根据已批准文档生成结构化 Todo

### execution
根据已批准 Todo 执行开发任务

---

## 编排原则

1. 任务必须有明确输入
2. 任务必须有可追踪状态
3. 任务结果必须可回放
4. 任务之间有前置依赖
5. 未批准不得进入下一阶段

---

## 基本状态

- queued
- running
- completed
- failed
- cancelled

---

## 输入输出原则

### 文档生成输入
- 用户需求
- 当前项目上下文
- 当前 `.osheep` 文档
- 用户补充说明

### 文档生成输出
- 文档变更列表
- 待确认项
- 结构化摘要

### Todo 生成输入
- 已批准文档
- 当前代码上下文

### Todo 生成输出
- Todo 列表
- 顺序与依赖
- 风险与备注

### 执行输入
- 已批准 Todo
- 当前代码上下文
- 项目设置

### 执行输出
- 执行日志
- 文件变更
- 完成状态
