# 后端接口架构

## 目标

为前端工作台提供文档、任务、工作区和 AI 调用的统一接口。

---

## 服务职责

### API 服务
负责：
- 接收前端请求
- 管理项目会话
- 读写 `.osheep` 文档
- 创建异步任务
- 推送任务状态

### Worker 服务
负责：
- 执行 AI 文档生成
- 执行 Todo 生成
- 执行开发任务
- 写回结果
- 更新状态

---

## 接口分组

### 项目接口
- 获取项目信息
- 获取 `.osheep` 结构
- 读取文档
- 写入文档

### AI 流程接口
- 提交需求
- 生成文档
- 修订文档
- 生成 Todo
- 启动执行

### 任务接口
- 查询任务列表
- 查询任务详情
- 获取日志流
- 中断任务
- 重试任务

### 设置接口
- 读取 `settings.json`
- 更新 `settings.json`

---

## 通信方式

- 普通请求使用 HTTP
- 日志与状态更新使用 WebSocket
- 长耗时流程通过异步任务执行
