## 🐛 已识别的问题

### 问题 1: 文本内容重复显示
**现象**: assistant 的回复内容出现两次一模一样的文本

**原因分析**:
- 在 `ChatTab.tsx` 第594行有重复检查逻辑
- 但检查可能不够准确，导致 `message.content` 和 `text step` 同时显示

**修复方案**:
```typescript
// 更严格的重复检查
const hasTextStep = steps.some(s => s.kind === "text" && s.text.trim() === message.content.trim());
```

### 问题 2: 工具步骤显示多余的白色状态点
**现象**: read/write 等工具步骤同时显示：
- 状态点（✓/运行中）
- 白色小圆点

**原因分析**:
- `workbench.css` 第1821行已有规则隐藏工具的白点
- 但可能 CSS 选择器不够精确

**修复方案**:
```css
/* 隐藏工具步骤的文本图标 */
.chat-step--tool .chat-step__icon--text,
.chat-step--tool.chat-step__icon--text {
  display: none !important;
}
```
